# LOBOTOMY DELUXE

謎の「収容体」を職員に管理させ、作業エネルギーを取り出しながら施設を運営するオリジナルのブラウザ管理シミュレーターです。

▶ プレイはこちら: https://kaikomziu.github.io/lobotomy-deluxe/

## 概要

- 職員を収容体に割り当てて「本能・洞察・愛着・抑圧」の4種の作業エネルギーを供給し、日々のノルマを達成します。
- 作業に失敗し続けると収容体の封印カウンターが減少し、0になると「収容違反(脱走)」を起こします。
- 脱走した収容体は放置すると職員を襲撃します。職員を割り当てて鎮圧しましょう。
- ノルマ未達成が続くと信頼度が低下し、0になると運営終了です。職員が全滅した場合も終了となります。
- コインで新規職員の雇用や、負傷した職員の休養処置が行えます。
- 収容体は全15種(ZAYIN〜ALEPH全5等級)、実績は41種類あります。

## 技術構成

- 依存ライブラリなしのバニラ HTML/CSS/JavaScript
- `js/data.js` : 収容体・職員名・実績のマスターデータ
- `js/game.js` : ゲームロジック本体
- `js/ui.js` : 画面描画・DOM操作
- `js/version.js` : 更新履歴管理
- セーブデータは localStorage に保存されます。
